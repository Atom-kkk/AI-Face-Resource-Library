      使用技巧

      • 把图片放进各类 AI 工具的「角色参考 / 人脸参考 / IP-Adapter」里，就能固定同一个人的长相。
      • 要统一脸，选正面人脸；要参考服装质感、发型细节和整体氛围，选造型。
      • 连续用同一张图当参考，出图与出视频的脸会更稳；换角度时优先换同一编号的造型图。
      • 下载原图（PNG）再喂给模型，细节比缩略图清楚得多。
      • 点开任意一张，右侧可以一键生成英文人像提示词，配合参考图一起用效果最好。

      AI 人像提示词

      需先在「AI 设置」填 DeepSeek API Key。提示词只存在本机浏览器。

      使用说明

      1. 找图：顶部搜索框支持编号（如 f71f980）、发长（短发 / 中短发 / 中长发 / 长发）与风格关键词（如 空气刘海、狼尾、挑染、米色），多个词用空格分隔表示「同时满足」。
      2. 分区：正面人脸 893 张，正面且纯色背景，最适合固定长相；造型 606 张，带服装与完整氛围，角度各异；收藏 是你自己点星标存下来的图。
      3. 快筛：发长下面那排虚线标签是风格关键词，点一下按「风格 + 发长」叠加筛选，再点一次取消。
      4. 放大：点任意一张图进入详情，← → 切换、Esc 关闭，手机上左右滑动。
      5. 下载：卡片右下角的「PNG」或详情里的「下载原图」，拿到的都是本地 1122×1402 / 1597×2000 左右的原尺寸 PNG，不是缩略图。
      6. 上传自己的图：点顶部「＋ 上传我的图」，拖拽或多选，每张都要选发长、填风格，否则存不进去。编号自动从 M-0001 起，图片只存在你自己的浏览器里。
      7. AI 提示词：在「AI 设置」填好 DeepSeek API Key 后，点开图片 → 右侧「AI 人像提示词」→「生成」，会按这张图的发长与风格写一条英文提示词，可编辑、可复制、自动保存。
      8. 主题：右上角太阳图标切换深浅色，默认跟随系统。
