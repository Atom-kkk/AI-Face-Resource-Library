# AI 模特脸参考库 · 中文汉化版

> 1499 张 AI 人脸参考图的**纯静态**图库：零依赖、零构建，可完全离线运行，支持搜索、收藏、上传自己的图与一键生成人像提示词。

**原图库：** <https://ai-portrait-gallery.pages.dev/>（`AIモデル顔データベース`）
**PNG 原图打包：** <https://pan.quark.cn/s/3c15a8a8a96f>（1499 张 1122×1402 / 1597×2000 无损，无需提取码）
**原作者：** あぎ · [@agi_aibusi](https://x.com/agi_aibusi)
**本仓库：** 在原站基础上的中文汉化 + 素材本地化 + 功能增强版

## 这是什么

原站是一套面向 AI 绘画与视频制作的**人脸参考素材库**：想在多张图、多段视频里保持同一个人，就得反复拿同一张正面脸当参考。它把素材分成两类——正面且纯色背景的「人脸」，以及带服装与完整氛围的「造型」，以 CC0 发布。

原站只有日文界面、图片走外链、没有搜索也没有收藏，翻到第几十张就找不回刚才那张。本项目在保留原站全部素材与视觉风格的前提下，做成一个**可以长期自己用下去**的工具：

1. **全站汉化** —— 界面文案、4 类发长、50 条发型风格描述全部译成中文，搜索也支持中文（`空气刘海`、`狼尾`、`挑染`）。
2. **素材完全本地化** —— 1499 张缩略图（400×500 WebP，30 MB）与 1499 张原图（PNG，4.53 GB）全部落在 `assets/`，字体也镜像到 `fonts/`，断网、无 CDN 也能正常浏览与下载。
3. **能找得到** —— 编号 / 发长 / 风格多词搜索、发长筛选、风格快筛、四种排序、收藏夹。
4. **能往里加东西** —— 上传自己的人脸图（拖拽/多选），指定分区、发长与风格，编号自动续号，存浏览器本地。
5. **能直接产出提示词** —— 点开任意一张图，点「生成」即调用 DeepSeek 写一条同款人脸的英文文生图提示词，可改、可复制、自动保存。
6. **零门槛运行** —— 三个文件，双击 `index.html` 就能用；也能扔到任意静态托管上。

## 功能

### 浏览与查找
- 三个分区页签：**正面人脸** 893 张、**造型** 606 张、**收藏**
- 搜索框支持编号（`f71f980`）、发长（`短发`）、风格词（`空气刘海`），空格分隔表示「同时满足」
- 发长筛选与风格快筛（波波头 / 狼尾 / 空气刘海 / 挑染 / 米色…）可叠加，标签上带实时计数
- 排序：默认顺序、按编号、按文件大小、最近上传优先
- 每批 120 张，滚到底自动追加；「加载更多」显示剩余数量
- 「随机」按钮：灵感枯竭时随便抽一张

### 灯箱
- 先出缩略图占位，原图解码完成后无缝替换
- 右侧信息面板：编号、分区、发长、风格、分辨率、原图体积、在列表中的位置
- `←` `→` 切换、`Esc` 关闭、关闭后焦点回到原卡片
- 一键下载原图 PNG、复制编号、收藏

### 上传与整理（数据存在浏览器本地）
- 「＋ 上传我的图」支持拖拽或选择文件，多选，JPG / PNG / WebP / HEIC 均可
- 每张**必须**选分区 + 发长 + 填风格，缺失时不允许保存
- 自动生成 400×500 缩略图（canvas → WebP），原图单独保存
- 编号从 `M-0001` 自动续号，删除后不回退、不重号
- 上传的图可删除；内置的 1499 张只读

### AI 人像提示词（需自备 DeepSeek API Key）
- 按该图的发长 + 风格写一条 60–90 词的英文提示词，覆盖脸型、五官、肤质、发型、妆容、光线、镜头、画质
- 提示词可手动修改、复制、自动保存；已有提示词的卡片左下角有 `AI` 角标
- 提示词模板（system prompt）可自行改写，固化自己的出图风格

## 数据结构

内置数据在 `assets/data.js`，为了体积用了短字段名：

```js
window.FACE_SECTIONS = [ { key:"face", name:"正面人脸", … }, { key:"styling", name:"造型", … } ];
window.FACE_LENGTHS  = ["短发", "中短发", "中长发", "长发"];
window.FACE_ITEMS = [
  { i:"f71f980dde3", s:0, l:0, t:"收颈短发（后颈偏长・空气刘海）", w:1122, h:1402, b:1895954 },
  /* … */
];
```

| 字段 | 示例 | 说明 |
| --- | --- | --- |
| `i` | `f71f980dde3` | 编号 = 原站文件名，缩略图 `assets/thumb/<i>.webp`、原图 `assets/full/<i>.png` |
| `s` | `0` / `1` | 分区：0 正面人脸，1 造型 |
| `l` | `0`–`3` | 发长索引，对应 `FACE_LENGTHS` |
| `t` | `收颈短发（…）` | 中文风格描述，空串表示该图没有细分类 |
| `w` / `h` | `1122 / 1402` | 原图尺寸 |
| `b` | `1895954` | 原图字节数，用于显示体积与按大小排序 |

上传的图片不在这个数组里，而是存浏览器（见下一节），加载时合并进 `ITEMS` 并带 `local` 标记。

## 本地存储与隐私

上传的图片、收藏、提示词、AI 设置**全部只存在你的浏览器**，不上传任何服务器：

| 位置 | 键名 / 库 | 内容 |
| --- | --- | --- |
| IndexedDB | `face-library` → store `items` | 上传图的原图 Blob + 缩略图 Blob 与元数据 |
| localStorage | `face.local` | IndexedDB 不可用时的降级存储（dataURL） |
| localStorage | `face.fav` | 收藏的编号数组 |
| localStorage | `face.prompts` | `{ 编号: 提示词 }` |
| localStorage | `face.ai` | DeepSeek Key / 接口地址 / 模型 / 模板 |
| localStorage | `face.seq` | 上传图的编号计数器 |
| localStorage | `face.theme` | 深浅色偏好 |

彻底清空：浏览器开发者工具 → Application → 清除本站点的 IndexedDB 与 Local Storage。

> **Key 的安全**：DeepSeek API Key 以明文存在 `localStorage`，只在你点「生成」时随请求发往你填的接口地址。公共电脑上不要填。

## 本地使用

**方式一：直接双击**

打开 `index.html` 即可，无需服务器、无需联网（AI 功能除外）。`file://` 下 Chrome 会禁用 IndexedDB，上传的图会自动改存 `localStorage`（容量约 5 MB，够存几张）。

**方式二：本地静态服务器（推荐）**

```bash
cd ai-face-library-zh
python3 -m http.server 8080
# http://localhost:8080
```

> ⚠️ `file://` 和 `http://localhost` 是**不同来源**，IndexedDB / localStorage 互不相通。上传过图片后请固定用同一种方式打开，否则会出现「之前上传的图不见了」。

## 部署

纯静态文件，扔哪都能跑：

| 平台 | 做法 |
| --- | --- |
| 任意静态托管 | 上传全部文件，入口 `index.html` |
| GitHub Pages | Settings → Pages → 分支 `main` / 根目录（注意 4.5 GB 的 `assets/full` 不要提交） |
| Cloudflare Pages / Vercel / Netlify | 构建命令留空，输出目录 `/` |
| 内网 / NAS | 放进 Web 目录即可 |

仓库含 `assets/full/` 约 4.5 GB，克隆与上传都很难受，所以它在 `.gitignore` 里。**没有 `assets/full/` 时页面依然能正常浏览**，只是卡片与灯箱的下载按钮会自动改指向原站（启动时用一次 `HEAD` 探测）。

## AI 提示词配置

1. 点右上「AI 设置」，填 [platform.deepseek.com](https://platform.deepseek.com/api_keys) 申请的 API Key，点「保存设置」→「测试连接」。
2. 接口地址默认 `https://api.deepseek.com`（OpenAI 兼容，路径 `/chat/completions`），模型默认 `deepseek-chat`，也可填其他兼容服务。
3. 点开任意图片 → 右侧「AI 人像提示词」→「生成」。

默认模板要求模型：只写画面本身（脸型五官 / 肤质 / 发型细节 / 妆容 / 光线 / 镜头构图 / 画质）、正面纯色背景半身像、60–90 个英文词、逗号短语、不要解释与负面词。想换成特写 / 侧脸 / 胶片风，直接在设置里改模板，`{{len}}` 与 `{{style}}` 会被替换成该图的发长与风格。

费用按 token 计，单张约几百 tokens，建议先拿几张试。

## 素材说明

| 层级 | 尺寸 | 本地化 | 体积 |
| --- | --- | --- | --- |
| 缩略图 `assets/thumb/` | 400×500 WebP | ✅ 1499/1499 | 约 30 MB |
| 原图 `assets/full/` | 1122×1402 / 1597×2000 PNG | 🟡 本地镜像，未入 git | 约 4.53 GB（每张约 3.09 MB） |

**原图怎么补回来？**

`assets/full/` 合计 4.53 GB，塞进 git 会让克隆、拉取和静态托管都很难受，所以走 `.gitignore`，不随仓库分发。三条路：

**① 网盘直接下（最省事）** —— <https://pan.quark.cn/s/3c15a8a8a96f>　1499 张无损 PNG 打包，无需提取码。解压后整个文件夹丢进 `assets/full/` 即可。

**② 从原站按编号拉** —— `https://ai-portrait-gallery.pages.dev/img/full/<编号>.png`，编号清单就是 `assets/data.js` 里的 `i` 字段。

**③ 已有文件直接拷** —— 文件名保持 `<编号>.png`（如 `f71f980dde3.png`）即可。

放进去后不需要改代码，刷新即可；启动时的 `HEAD` 探测会自动把下载按钮切回本地 PNG。

## 常见问题

**上传的图刷新后不见了？**
换过打开方式（`file://` ↔ `http://localhost`），两者存储隔离；也可能是清过浏览器数据。

**`file://` 下上传提示存不下？**
该环境禁用了 IndexedDB，走了 `localStorage` 兜底，容量只有 5 MB 左右。起一个本地服务器即可正常存。

**点生成提示词报 `HTTP 401`？**
Key 无效或余额不足；重新填一份，再点「测试连接」。

**提示「网络或跨域请求失败」？**
接口地址填错、网络不通，或换成了不支持浏览器跨域的第三方服务。

**下载按钮提示「下载原图（原站）」？**
说明本地没有 `assets/full/`，页面自动回退到原站下载（需联网）。按上一节把 PNG 放回去即可。

**为什么有些图没有风格名？**
原站数据里有 755 张只标了发长、没有细分风格，这里如实保留，显示为「—」。
